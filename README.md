## 🌍 Overview

WattSwap is a smart energy-sharing ecosystem designed to connect energy producers and consumers in real time.

The platform combines:

- ⚡ Renewable energy trading
- 🤖 AI-based surplus & demand prediction
- 🔗 Blockchain transaction logging
- 📊 Real-time monitoring dashboards
- ☁️ Cloud deployment support

Users with excess renewable energy can trade with nearby users needing power, creating a sustainable and decentralized energy marketplace.

# 🚀 Getting Started

## Prerequisites

Ensure you have installed:

- Node.js >= 18
- MongoDB
- Python >= 3.10
- MetaMask Wallet
- Git

---

## ⚙️ Installation

### 1️⃣ Clone Repository

```bash
git clone https://github.com/rohithjagan/wattswap.git
cd wattswap
```

### 2️⃣ Install Frontend Dependencies

```bash
cd frontend
npm install
```

### 3️⃣ Install Backend Dependencies

```bash
cd ../backend
npm install
```

### 4️⃣ Setup AI Environment

```bash
cd ../ai-model
pip install -r requirements.txt
```

### 5️⃣ Configure Environment Variables

Create a `.env` file using `.env.example`.

### 6️⃣ Start Development Servers

#### Frontend

```bash
npm run dev
```

#### Backend

```bash
npm run server
```

#### AI Service

```bash
python app.py
```
