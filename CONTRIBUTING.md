# 🤝 Contributing to WattSwap

Thank you for considering contributing to WattSwap!

We welcome contributions from developers, designers, researchers, and open-source enthusiasts.

---

# 📌 How to Contribute

## 1️⃣ Fork the Repository

Click the **Fork** button on GitHub.

---

## 2️⃣ Clone Your Fork

```bash
git clone https://github.com/your-username/wattswap.git
```

## 3️⃣ Create a Branch

```bash
git checkout -b feature/your-feature-name
```

---

## 4️⃣ Make Changes

Implement your feature or fix.

---

## 5️⃣ Commit Changes

```bash
git commit -m "Add: your meaningful commit message"
```

---

## 6️⃣ Push Changes

```bash
git push origin feature/your-feature-name
```

---

## 7️⃣ Open Pull Request

Submit a pull request describing your changes.

---

# ✅ Contribution Guidelines

- Write clean and maintainable code
- Follow project folder structure
- Use meaningful commit messages
- Test your code before submitting
- Keep pull requests focused
- Avoid committing secrets or credentials

---

# 🐛 Reporting Bugs

Please include:

- Bug description
- Steps to reproduce
- Expected behavior
- Screenshots/logs if applicable

---

# 💡 Feature Requests

Feature suggestions are always welcome.

Open an issue with:

- Problem statement
- Proposed solution
- Benefits

---

# 🧪 Development Standards

## Frontend

- Use reusable React components
- Maintain responsive UI
- Follow Tailwind conventions

## Backend

- Follow REST API standards
- Use proper error handling
- Validate all inputs

## Blockchain

- Write secure smart contracts
- Avoid gas inefficiencies

## AI

- Document model assumptions
- Keep datasets clean

---

# 📜 Code of Conduct

By contributing, you agree to follow the project's `CODE_OF_CONDUCT.md`.

Thank you for contributing ❤️
